# Employee-Management-System-Python-MySQL-

A simple database-driven Employee Management System built with Python and MySQL.
It supports basic CRUD-style operations through a CLI menu:

- Add Employee
- Remove Employee
- Promote Employee (salary increase)
- Display Employees

This project demonstrates connecting Python to MySQL, executing parameterized SQL queries, and persisting data across sessions.

---

## Tech Stack
- Python 3
- MySQL (Homebrew / local install)
- mysql-connector-python

---

## Features
✅ Add employees to a MySQL table  
✅ Remove employees by ID  
✅ Promote employees by increasing salary  
✅ Display all employees
